명함인식 개인정보처리방침

시행일: 2026년 7월 21일 · 앱: 명함인식 (Android)

핵심 요약 — 명함인식은 개발자의 서버를 운영하지 않습니다. 촬영한 명함과 인식된 정보는 사용자의 휴대폰과 사용자가 선택한 본인 구글 주소록에만 저장되며, 개발자는 사용자의 개인정보를 수집·보관하지 않습니다.

1. 수집·저장하는 정보

앱을 사용하면 다음 정보가 생성될 수 있으며, 이는 모두 사용자 기기 내부 또는 사용자가 선택한 본인 구글 주소록에만 저장됩니다.

  • 촬영한 명함 사진
  • 명함에서 인식된 정보(이름, 회사, 부서, 직함, 전화번호, 이메일, 주소, 홈페이지 등)
  • 사용자가 등록한 Gemini API 키 및 저장 형식 등 설정값

이 정보들은 개발자의 서버로 전송되거나 수집되지 않으며, 개발자는 이에 접근할 수 없습니다.

2. AI 명함 인식

명함 정보 인식을 위해, 사용자가 Google에서 발급받은 무료 AI 키를 앱에 직접 등록해 사용합니다. 명함을 촬영하면:

  • 명함 사진이 인식을 위해 Google(Gemini) 서버로 전송되어, 사진 속 글자를 정보로 읽는 용도로만 사용됩니다.
  • 개발자는 이 사진이나 인식 결과를 수집·보관하지 않습니다.
  • 등록한 AI 키 역시 사용자 휴대폰에만 저장됩니다.
  • Google에서의 데이터 처리는 Google의 개인정보처리방침을 따릅니다.

3. 주소록(연락처) 접근

인식한 명함 정보를 연락처로 저장하기 위해 주소록 권한을 사용합니다.

  • 주소록 쓰기 — 인식된 명함 정보를 사용자의 연락처로 저장합니다.
  • 주소록 읽기 — 이미 저장된 사람인지 확인해 중복 저장을 방지합니다.
  • 계정 목록 — 어느 구글 계정에 저장할지 사용자가 선택할 수 있도록 기기의 계정 목록을 조회합니다.

이 과정은 모두 기기 안에서 이루어지며, 주소록 내용은 개발자의 서버로 전송되지 않습니다. 저장된 연락처는 사용자가 선택한 구글 계정을 통해 사용자 본인의 구글 주소록으로 동기화될 수 있습니다.

4. 앱 권한

  • 연락처 읽기/쓰기 — 명함 정보 저장 및 중복 확인
  • 계정 목록 — 저장할 구글 계정 선택
  • 인터넷 — AI 명함 인식(Gemini) 호출

명함 촬영은 기기의 기본 카메라 앱을 통해 이루어지므로 별도의 카메라 권한을 요구하지 않습니다. 각 권한은 해당 기능을 사용할 때만 쓰입니다.

5. 제3자 제공

개발자는 사용자 정보를 제3자에게 판매·제공하지 않습니다. 위 2항의 Google(Gemini AI) 처리는 명함 인식 기능 제공을 위한 것이며, Google의 정책을 따릅니다.

6. 데이터 보관 및 삭제

앱 내부에 저장된 설정값과 AI 키는 앱을 삭제하면 함께 삭제됩니다. 다만 이미 주소록에 저장된 연락처는 휴대폰(및 구글 주소록)에 남아 있으므로, 삭제를 원하면 주소록에서 사용자가 직접 삭제할 수 있습니다.

7. 아동의 개인정보

본 앱은 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
