AI골프스코어 개인정보처리방침

시행일: 2026년 10월 14일 · 앱: AI골프스코어 (Android)

핵심 요약 — AI골프스코어는 사용자의 라운드 기록·이름·사진 등 모든 정보를 사용자의 휴대폰 안에만 저장합니다. 개발자는 별도의 서버를 운영하지 않으며, 사용자의 개인정보를 수집·보관하지 않습니다. 다만 AI 인식(2항), 골프장 자동 입력(3항), 공지 알림(4항)을 쓸 때 필요한 정보만 해당 외부 서비스로 전송됩니다.

1. 수집·저장하는 정보

앱을 사용하면 다음 정보가 생성될 수 있으며, 이는 모두 사용자 기기 내부에만 저장됩니다.

  • 라운드 기록(골프장명, 날짜, 점수), 동반자 이름, 승·무·패 기록
  • 사용자가 촬영하거나 앨범에서 불러온 스코어 사진
  • 사용자가 직접 입력한 본인 이름 등 설정값

이 정보들은 개발자의 서버로 전송되거나 수집되지 않으며, 개발자는 이에 접근할 수 없습니다.

2. AI 정밀 인식 (선택 기능)

사용자가 직접 발급받은 AI 키를 앱에 등록하면 스코어카드 사진을 AI로 읽을 수 있습니다. 등록한 키에 따라 아래 서비스 중 하나로 전송됩니다.

  • Google Gemini (Google LLC) — Gemini 키를 등록한 경우
  • Claude (Anthropic PBC) — 클로드 키를 등록한 경우 (이 경우 클로드만 사용)

이 기능을 사용할 경우:

  • 스코어 사진이 사진 속 점수를 텍스트로 읽는 용도로 전송됩니다.
  • 인식 정확도를 위해 사용자가 입력한 본인 이름과 이전 동반자 이름이 사진과 함께 전송됩니다 (사진 속 이름을 같은 철자로 읽도록 돕는 용도).
  • 개발자는 이 사진·이름·인식 결과를 수집·보관하지 않습니다.
  • 등록한 AI 키는 사용자 휴대폰에만 저장됩니다.
  • 전송된 데이터는 각 서비스의 개인정보처리방침과 보관 정책을 따르며, 일정 기간 해당 서비스에 보관될 수 있습니다.

AI 키를 등록하지 않으면 사진은 외부로 전송되지 않습니다.

3. 위치 정보 (골프장 자동 입력)

  • 수집 시점:
    • 앱의 [촬영] 버튼으로 스코어카드를 찍을 때 휴대폰의 현재 위치 1회
    • 갤러리에서 사진을 고를 때, 그 사진 파일에 기록된 촬영 위치(사진에 위치가 기록된 경우에만)
  • 이용 목적: 촬영한 곳 근처의 골프장 이름을 자동으로 입력
  • 처리 방법: 위치(위도·경도)를 카카오 로컬 API(카카오㈜)로 보내 반경 2km 안의 골프장을 검색합니다. 위치는 검색에만 쓰이며 앱과 개발자 어디에도 저장하지 않습니다. 기록에는 골프장 이름만 남습니다.
  • 거부 권리: 위치 권한을 허용하지 않아도 앱의 모든 기능을 사용할 수 있습니다. 사진 위치 권한을 허용하지 않아도 사진은 고를 수 있으며, 이 경우 갤러리 사진의 촬영 위치는 쓰지 않습니다. 또한 휴대폰 카메라 설정에서 위치 태그를 끄면 사진에 촬영 위치가 기록되지 않습니다. 위치를 쓰지 않는 경우 골프장 이름은 스코어카드에서 읽거나 직접 입력합니다.
  • 촬영 시각: 사진에 기록된 촬영 시각은 라운드 시각을 자동으로 입력하는 데 쓰이며, 휴대폰 안에서만 처리되고 외부로 전송되지 않습니다.

4. 푸시 알림

업데이트·공지 안내를 위해 Firebase Cloud Messaging(FCM)을 사용합니다. 알림 전송에 필요한 기기 등록 토큰이 Google/Firebase를 통해 처리되며, 이는 특정 개인을 식별하는 용도로 사용되지 않습니다. 기기 설정에서 알림을 끄면 수신되지 않습니다.

5. 앱 권한

  • 카메라 — 스코어 사진 촬영 (기기의 기본 카메라 앱 사용)
  • 위치 — 촬영할 때 근처 골프장 찾기 (앱 사용 중에만, 백그라운드 위치 사용 안 함)
  • 사진 선택 및 사진 위치 — 사진은 시스템 사진 선택 화면에서 사용자가 고른 것만 앱에 전달됩니다 (휴대폰의 모든 사진을 읽는 권한은 사용하지 않습니다). 안드로이드는 앱에 사진을 넘길 때 촬영 위치를 지우기 때문에, 고른 사진의 촬영 위치를 읽기 위해 사진 위치 권한을 사용합니다. 사용자가 고른 사진 외의 다른 사진은 읽거나 저장하거나 전송하지 않습니다.
  • 알림 — 공지 알림 표시

각 권한은 해당 기능을 사용할 때만 쓰이며, 거부해도 다른 기능은 정상 이용할 수 있습니다.

6. 제3자 제공 및 외부 서비스

개발자는 사용자 정보를 제3자에게 판매·제공하지 않습니다. 아래 외부 서비스는 해당 기능을 제공하기 위해서만 사용합니다.

  • 카카오㈜ — 위치로 골프장 검색 (3항)
  • Google LLC — 스코어카드 인식(Gemini, 2항), 공지 알림(Firebase, 4항)
  • Anthropic PBC — 스코어카드 인식(Claude, 선택, 2항)

7. 데이터 보관 및 삭제

모든 데이터는 기기 내부에 저장되므로, 앱을 삭제하면 관련 데이터도 함께 삭제됩니다. 기기 변경 시에는 앱의 백업(CSV 파일 내보내기) 기능으로 사용자가 직접 이전할 수 있습니다.

8. 아동의 개인정보

본 앱은 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
